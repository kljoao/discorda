# 0006 — LiveKit self-hosted desde o primeiro teste

Status: Aceito pelo usuário em 28/09/2026.
Data: 28/09/2026.

## Context

Até 15 publicadores com webcam e tela tornam upload mesh e manutenção de conexões pouco adequados.

## Decision

Usar LiveKit self-hosted em nó único. .NET controla admissões e grants por sala; renderer usa SDK JS; API interna e webhooks ficam encapsulados em adaptador. Simulcast/adaptive stream/dynacast reduzem assinaturas desnecessárias.

## Alternatives

mediasoup exige mais construção de signaling/sessões. Janus é alternativa de gateway/plugins. LiveKit Cloud transfere operação e oferece recursos adicionais, com custo a avaliar.

## Consequences

Egress pode dominar custo. Remover participante self-hosted não revoga tokens emitidos, inclusive renovados. Bloqueio forte recomendado exige rotação de chave e restart com interrupção das chamadas; aceitar explicitamente ou rever fornecedor. TTL inicial curto sozinho não resolve.
