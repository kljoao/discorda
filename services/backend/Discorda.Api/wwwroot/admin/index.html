Pessoas autorizadas

    Rede Radmin

    Um IPv4 por linha. Salvar prepara a política; depois baixe e execute o script como administrador no host Windows. O Docker não altera o Firewall do Windows.

    O script modifica somente regras “Discorda SelfHost”. Regras amplas de Docker ou de versões antigas podem permitir conexões fora desta lista: revise-as no Firewall antes de convidar pessoas.

    Login Google

    Para o primeiro login, configure Google no dashboard do Supabase. Depois, este formulário permite atualizar o provedor. O segredo permanece no Supabase; os campos abaixo nunca são preenchidos com valores salvos.

    Use um PAT com acesso ao projeto. Não use publishable, anon, secret ou service_role neste campo. O token é usado somente nesta operação e não é armazenado pelo Discorda.
